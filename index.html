Controls

↑ / ↓ surf channels or move guide focus. G or Y opens the guide. Enter / A confirms. Esc / B closes the guide or opens it from failure. F toggles fullscreen. S opens Settings. D opens Diagnostics. C / Menu opens controls. M toggles mute. Space plays/pauses. [ / ] changes channels.

Xbox mapping requires hardware verification. Directional holds repeat after 350 ms, then every 160 ms. A/B/Y are edge-triggered. Edge may reserve B or keep input inside an external iframe; use the on-screen FULL SCREEN button or Edge’s cursor if needed.
