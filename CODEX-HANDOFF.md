## Local run

Windows: install Node.js LTS if necessary, then double-click `Start-Garage-TV.cmd`. It builds and runs the server without installing packages. Open http://localhost:4173/garage-tv/ and keep the terminal open.

Cross-platform:

```sh
npm run build
npm run serve
```

To test on Xbox over the home network before publishing, run the server on the PC and open `http://PC_LAN_IP:4173/garage-tv/` in Xbox Edge. The server binds to the network; permit port 4173 on the private network only if needed. Stop the server when finished. GitHub Pages supplies HTTPS and does not require the PC to remain on.
