# Xbox One acceptance checklist

This is a **manual acceptance checklist**, not a claim that the application has been tested on Xbox One. Automated browser checks run in desktop Chromium with a controlled YouTube API and simulated controller.

1. Publish the repository using README.md's GitHub Pages steps. Confirm the workflow succeeds and open the resulting URL on your PC first. The expected project address is `https://wussuplee.github.io/garage-tv/`; it is not live until deployment succeeds.
2. In Xbox Settings → General → TV & display options, select 720p if your display supports that mode. Ensure the Xbox clock is correct and connect to the internet.
3. Launch Microsoft Edge on Xbox One. Enter the verified Pages URL. Bookmark it. Use Edge full-screen if available; check that TV overscan does not crop the header or bottom controls.
4. Initially, playlists are empty because discovery failed. Open Settings, select 001 and paste a public YouTube playlist URL from your account. Save. Repeat for 002–004. If typing is awkward, configure on your PC, Export JSON and replace the deployable `data/default-config.json`; browser storage does not transfer automatically between PC and Xbox. Never paste an API key or credentials.
5. Reload several times. With configured channels, startup should choose 001–004, excluding 000, disabled channels and empty sources. A source can still be non-embeddable even when its URL is valid.
6. If sound/video does not start, focus **Start / retry playback** using the cursor or keyboard and press A/Enter. If Edge reserves A, activate the native YouTube Play control. Confirm audio comes from only one video. Toggle Mute and Unmute.
7. Open Diagnostics and press each controller button. Record which raw button indices appear, the controller ID, and mapping. Check D-pad up/down, A, B, LB and RB. A mapping of `standard` enables proposed controls; unknown mappings only show diagnostics. Some Xbox/Edge buttons may remain reserved and may never reach the page.
8. With page controls focused: D-pad up/down should switch channels; LB/RB should also switch. Hold a bumper for two seconds: only one switch should occur. Release and press again: one further switch. In the guide D-pad up/down selects and A tunes. B toggles the guide or closes another panel. Input can stop reaching the application while focus is inside the YouTube iframe; move back using Tab or Edge's cursor.
9. Test visible CH−/CH+, Guide, Play/Pause, Mute, Settings and Diagnostics using the controller's browser cursor. For a keyboard fallback use ↑/↓, G, Enter, Esc, S, D, M, Space and [/]. Keyboard shortcuts deliberately do not capture typing in settings inputs.
10. Open the guide during playback. The video should continue in the reduced player. Check TUNED versus focused selection, NOW/NEXT, scrolling through all rows and closing without changing the channel.
11. Watch to a playlist video's end and confirm advancement and looping. Switch away and return: unscheduled playlist mode resumes its saved position, with no claim of advancement while away. Test a removed/private/non-embeddable video: bounded skipping or a readable retry state should appear. Regional, login and age restrictions are controlled by YouTube.
12. For actual virtual TV testing, configure a verified-duration manifest using SCHEDULES.md. Note the current video's time, leave for five minutes and return. Compare expected wall-clock offset to the actual player position. Repeat across a program boundary, refresh, pause/resume, and background/foreground. Record buffering and ads. Do not call synchronization verified until this passes on the console.
13. In 000 LIVE SPORTS, select Kobra matches. It must navigate in the same tab, without Garage TV opening another window. Use Edge's Back command to return. Garage TV cannot stop pop-ups or ads generated by the third-party service. Validate that the source is authorized and usable on your console; direct linking is not a claim of endorsement or rights verification.
14. Add, edit and remove a service in Settings, then reload to check persistence. Export/import a configuration; invalid JSON and invalid playlist URLs should leave the previous configuration intact. Xbox file selection/download support can vary; copy/paste JSON remains available.
15. Leave a channel running 30–60 minutes. Check heat/performance, audio, video advancement and responsiveness. Try 1080p too. If a problem occurs, record the URL, Edge version from Diagnostics, channel, error text, raw controller input, and exact steps.
